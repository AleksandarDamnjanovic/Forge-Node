System Presentation

True Control Over Your Automation Stack

01 // REAL-TIME CONTROL
script.fn Live Reload Ready
01 Script-Based & Privacy-First

Forge Node is a script-based, privacy-first automation platform for people who want their smart home, greenhouse, lab, or small factory to stay truly under their control. Instead of wrestling with both hardware wiring and software every time something needs to change, you set up your nodes once. From that moment on, the entire behavior of the system lives in a simple, readable .fn script that you can edit and reload in real time.

02 // HARDWARE & AAU CORE
ESP32 / ESP8266 / Arduino Encrypted MQTT
02 High-Level Primitives

The system is built around high-level primitives — switches, sensors, transmitters, and programs — rather than pins, voltages, or low-level firmware details. Nodes can be based on ESP32, ESP8266, Arduino, or other supported microcontrollers. Once they are running, you can reconfigure logic, add new rules, or completely rewrite how devices interact without soldering, without a multimeter, and without reflashing a single board. Everything stays yours.

03 Auxiliary Automation Unit (AAU)

At the heart of Forge Node is the AAU (Auxiliary Automation Unit), a Python-based interpreter that reads your .fn script and coordinates the whole network over encrypted MQTT. It has full visibility of every node and a dedicated administrative channel, so live changes take effect without restarting the system. Communication is encrypted by default, and the design deliberately avoids cloud lock-in or data harvesting.

03 // COMPLETE ECOSYSTEM
Docker :10011 Web UI + Android + AI Skill
04 Self-Contained Stack & AI Skill

Forge Node ships as a complete, self-contained solution: firmware for the nodes, a modern web interface, an Android app, Docker support for easy local deployment, and even an AI skill that lets agents understand and operate the system. You can run everything locally today, split it into modular or remote groups when needed, or integrate your own software through language wrappers. The recommended path is simply building the Docker image and starting the stack — the web UI appears on port 10011.

05 Self-Hosted or Managed

While the system is fully self-hostable and designed to run under your own control, work is also underway on a managed web service and hosting platform for Forge Node. The goal is to give people who prefer not to manage their own infrastructure an easy way to use the same privacy-first automation model, without giving up ownership of their logic or data.

04 // BUILT FOR MAKERS
No Cloud Lock-In 100% Ownership
06 Unrestricted DIY & Industrial Freedom

Because the logic lives in an open, human-readable script and the entire stack runs under your control, Forge Node is especially suited for DIY builders, experimenters, and anyone who has grown tired of proprietary ecosystems that quietly collect data or restrict what you can change. There are no artificial feature gates and no forced cloud accounts. Whether you are automating lights and climate at home, monitoring a greenhouse, or building a small industrial setup, Forge Node lets you define the behavior once in plain language and keep evolving it — without ever losing ownership of the system.
